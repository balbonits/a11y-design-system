## What changed

- kinetic's `--font-display`, `--font-body` and `--font-mono` now name `"<Family> Fallback"` second:
  `'Bricolage Grotesque', 'Bricolage Grotesque Fallback', 'Arial Narrow', system-ui, sans-serif`,
  `'Instrument Sans', 'Instrument Sans Fallback', system-ui, sans-serif`,
  `'IBM Plex Mono', 'IBM Plex Mono Fallback', ui-monospace, monospace`.
  Source edit is `src/themes/kinetic.css`; `src/tokens/themes.css` and `src/tokens.json` are regenerated by `npm run tokens`.
- Why: Visual QA failed devtool-dashboard #5 on the font swap (CLS 0.0196 at 320px, a 24px jump). The app defines
  metric-matched `local()` faces under these names; Ember only names them. Ruling: Chief Architect, with Chief of Creatives agreeing.
- README and the kinetic theme header say the same. Ember still ships no fonts or `@font-face` rules.
