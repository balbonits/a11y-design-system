# Contrast and theme contract

Generated by `npm run contrast` from every registered theme (src/themes/registry.json). Text needs 4.5:1, UI (borders, focus ring) 3:1.

Open-modal rule (Chief Architect, v0.3.1, WCAG 1.4.11): the dialog border (or the dialog surface when its border width is 0) reaches 3:1 against `--scrim` alpha-composited over `--color-bg`, in light and dark. Page text under the scrim: `--text-muted` composited under the scrim reaches 3:1 against the composited `--color-bg`, and the scrim never lightens `--color-bg` (the design CONTRAST Scrim sections). Dialog text sits on the dialog's own opaque surface, so it has no scrim check.

Focus ring rule (Chief Architect, v0.3.1): `--focus-ring-offset` must be 0 or more. The focus ring color must reach 3:1 against every surface a control can sit on (`--color-bg`, `--surface`, which cards and raised controls use, and `--surface-muted`) in light and dark, at any offset. When the offset is 0 the ring also touches the control border, so focus ring vs `--border` is required too; when the offset is above 0 the ring sits on the page and that pair is not required.

`--hue-shift` rule (Chief Architect, v0.3.1): a unitless multiplier from 0 to 1, with any unit rejected. Neutral default 0, and 0 under reduced motion. The maximum angle lives in the consuming CSS, as `calc(var(--hue-shift) * 40deg)`.

`--press-offset` rule (ARCH-REVIEW Addendum 8): a non-negative px length (unitless and negative rejected), 0px under reduced motion.

## Optional hover pair (ARCH-REVIEW Addendum 10)

For each theme that defines `--hover-fill` and `--hover-label` (optional contract tokens, a pair, not @property-registered): label on fill 4.5:1, fill against `--color-bg` and `--surface` 3:1 (primary, ghost and danger have no visible border), and the focus ring against the fill 3:1 only when the ring can overlap it (offset 0 or less). Such a theme keeps `--focus-ring-offset` at 2px or more (video-player HANDOFF:68-69). Themes without the pair keep each variant's own hover.
