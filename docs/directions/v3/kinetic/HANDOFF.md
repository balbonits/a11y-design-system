# D "kinetic" HANDOFF: dev dashboard identity (plus the shared Ember sampler)

Identity for the **dev dashboard** (per neo/HANDOFF.md: job tracker = dusk, dev dashboard = kinetic, Ember UI + Storybook = neo). Kinetic Swiss: warm white paper, cobalt type and hairline rules, one signal red for action, big variable-weight display type on an asymmetric 12-column grid, no cards and no shadows. Dark mode is a cobalt night with warm white type. The prototype also draws the Ember sampler and the job tracker board in this direction, because BRIEF.md asks each direction to show all 3 screens. **Primary project: dev dashboard. Builder: FSD registers the kinetic theme tokens in Ember (R-2); FED applies them in the dev dashboard app. The Ember sampler and tracker views are a style sampler only, not for build** (Chief of Creatives scope ruling, 2026-11-10). Their sections below are kept as reference for how the tokens behave; build only the dev dashboard parts.

- Prototype: [index.html](https://raw.githack.com/balbonits/a11y-design-system/main/docs/directions/v3/kinetic/index.html) (views `#components`, `#tracker`, `#dashboard`, `#tokens`, with a light/dark toggle)
- Tokens: [TOKENS.md](TOKENS.md), [tokens.css](tokens.css), [tokens.json](tokens.json) (registry-ready, theme id `kinetic`, modes `light` and `dark`), generated by `gen.py` with `../shared/tokgen.py`
- Contrast: [CONTRAST.md](CONTRAST.md), 60 pairs, 0 fails (`node ../shared/contrast.mjs kinetic` from `..`)
- Screens: [handoff/](handoff/), plain and annotated, every view at every width in light and dark
- Re-run checks locally: `python3 -m http.server 8942` in `docs/directions/v3`, then from `docs/directions/v3` run `node shared/annotate.cjs kinetic http://127.0.0.1:8942/kinetic/index.html` (axe, overflow, text spacing, 200% zoom, annotated shots for all 4 views) and from `docs/directions` run `node v3/shared/shoot.cjs kinetic http://127.0.0.1:8942/kinetic/index.html` (375 and 1280 shots). ## H-1 Layout, mobile-first
320 is the base. Breakpoints use `min-width` only:

| Name | Query | What changes |
|---|---|---|
| base | none (320+) | One column. The section label rail ("01 Form") sits above its content. Nav links sit on their own full-width row under the logo and scroll sideways if they ever don't fit. Stats 2 across. Tracker stages stack top to bottom, each with a 2px cobalt rule on top. Side padding 1.25rem. |
| sm | `(min-width: 700px)` | The Form block's two halves (fields, checkboxes) go side by side. |
| md | `(min-width: 900px)` | 12-column grid turns on: the rail takes columns 1 to 3, content 4 to 12 (offset blocks 5 to 12). Nav moves inline between the logo and the mode toggle. Stats 4 across. Side padding 2.5rem. The States panel goes 3 across at 760px (shared `states.css`). |
| lg | `(min-width: 1000px)` | Tracker stages sit 5 across, separated by 1px `--border-subtle` vertical rules with 1.1rem padding either side. |

Frames: 320, 375, 768, 1024 and 1440 for every view, in [handoff/](handoff/) as `kinetic-<view>-<width>-<light|dark>.png`.

## H-2 Fluid rules
- Content max width 1320px (`.wrap`), side padding 1.25rem below 900px and 2.5rem from 900px.
- Grid: `grid-template-columns: minmax(0,1fr)` at base and `repeat(12, minmax(0,1fr))` from md; every grid child has `min-width: 0`, so long content can't widen the page.
- Type: body 1.0625rem (17px) with line height 1.6; never below 16px for body copy. Hero h1 `clamp(3rem, 13.5vw, 10.5rem)`, line height 0.9. View titles (Board, Overview, Tokens) `clamp(2.8rem, 11vw, 7rem)`. Section h2 1.6rem, stage h2 1.5rem, card h3 1.35rem, dialog h2 2rem, stat numbers `clamp(3.5rem, 12vw, 6.5rem)` at weight 800. Mono labels 0.8rem uppercase with 0.06em tracking; they are never the only label.
- Display weight follows scroll: from 800 (`--weight-display-max`) at the top down to 300 (`--weight-display-min`) after 600px of scroll, scaled by `--weight-shift` (0 under reduced motion, so the weight stays at `--weight-display` 700).
- Line length: lede 44ch, tab panels 56ch, token note 60ch.
- Tables sit in a focusable scroll region (`tabindex="0"`, `role="region"`, label "Components table, scrolls sideways") with a 480px min table width, so only the table scrolls, never the page.
- Dialog width `min(480px, 100vw - 2rem)`; toast `max-width: calc(100vw - 2rem)`, pinned 1rem from the bottom left.
- The build-time chart is an SVG at 100% width and 150px tall; it is decorative and the trend is stated in text ("Example, last 7 days. Down 38%.").
- No fixed heights on text containers. Controls set `min-height`, so text spacing and 200% zoom grow them instead of clipping.

## H-3 Nav per breakpoint
- "Skip to content" is the first Tab stop and moves focus to `<main id="main" tabindex="-1">` (no visible ring on main itself; it is a programmatic target).
- Header (sticky, `--color-bg` fill, 1px cobalt bottom rule): logo link "Ember UI v3 / D kinetic" (44px tall), `<nav aria-label="Prototype screens">` with four text links, then the mode toggle button.
- Current link: `aria-current="page"` plus a 3px `--accent` underline; hover shows a 3px `--border` underline. Both are underline weight changes, not color alone.
- base to md: the nav row is full width under the logo and toggle and scrolls sideways if needed (4 items fit at 320). No menu button with 4 items. If a product nav grows past six items, collapse it into a "Menu" disclosure (`aria-expanded`, `aria-controls`) below md.
- md and up: nav sits inline between logo and toggle.
- Route change (hash) moves focus to main and scrolls to the top; each view has its own h1.
- Under the header sits the release-notes ticker band (`role="region"`, label "Release notes ticker") with its "Pause ticker" button.
- Focus order at every width: skip link, logo, nav links left to right, mode toggle, "Pause ticker", then main content top to bottom. It matches visual order; the annotated shots number every stop.
- Mode toggle: label states the action ("Dark mode" or "Light mode"), no `aria-pressed` (the label already changes); choice is stored in `localStorage` under `jdilig:mode`, else `prefers-color-scheme` decides. A polite toast says "Dark mode on" or "Light mode on".

## H-4 Component states
Every state has a non-color cue.

| State | Treatment |
|---|---|
| Default button | Transparent fill, 2px `--border` outline, `--radius-md` (2px), 48px visual height (`--control-height`), 1.3rem side padding (`--control-padding-x`), 0.6rem icon gap (`--control-gap`). Primary: `--accent` fill and border, `--accent-contrast` text. Danger: `--danger` fill, `--danger-contrast` text. Text button: no border, 2px underline. |
| Hover | Default inverts (`--text` fill, `--color-bg` text). Primary goes to `--accent-hover`; danger to `--danger-hover`; text button turns `--accent`. A trailing arrow moves 4px right (`--duration-base`). |
| Focus-visible | 3px solid `--focus-ring-color` (cobalt-700 `#1434B8` light, `#C2CFFF` dark) with a 3px offset. Ring contrast 8.95 on bg, 9.49 on surface, 8.20 on surface-muted (light); 12.14, 11.10, 9.82 (dark). On the ticker band the ring switches to `--highlight-contrast` (8.95 light, 6.95 dark on `--highlight`). |
| Active / pressed | Moves down 1px (none under reduced motion) and keeps the hover fill; primary uses `--accent-hover`. |
| Disabled | `disabled` attribute, dotted `--text-muted` border, `--surface-muted` fill, `--text-muted` text, `not-allowed` cursor, plus visible hint text giving the reason ("Fill in the required fields to save."). |
| Error (field) | `aria-invalid="true"`, the underline goes to `--danger` at `--border-width-strong` (3px), message linked by `aria-describedby` in `--danger` bold with a "!" badge (`--danger` fill, `--danger-contrast` glyph, `aria-hidden`). Focus moves to the first invalid field on submit. |
| Disabled field | Dotted underline, `--surface-muted` fill, `--text-muted` text, hint "Set by your admin." |
| Loading | Busy button: `aria-busy="true"`, a 1em ring spinner and a verb label ("Saving…"). Lists and tables: three `aria-hidden` skeleton bars (1.1rem tall, `--surface-muted`, widths 100%, 80%, 60%) with `aria-busy="true"` on the container and one polite `role="status"` line ("Loading rows"). No shimmer at all. Under reduced motion the spinner stops and turns dotted. |
| Empty | Dashed `--border-subtle` box on `--surface-muted` with one bold line ("No rows to show."), plus one action where the copy gives one ("Add role", "Go to Board"). Empty tracker stage: "No roles in Closed." in `--text-muted`. |
| Load error | "!" badge plus "Couldn't load rows." in `--danger`, and a "Retry" button. Present on load it's a static region; when it appears after load it carries `role="alert"` (the prototype's Retry shows this). |
| Selected (tabs, nav) | Tabs: `--text` label plus a 3px `--accent` underline, `aria-selected="true"`; unselected tabs are `--text-muted` with no underline. Nav: 3px `--accent` underline plus `aria-current="page"`. |
| Status labels | Uppercase mono text always shown ("Passing", "Review", "Failing", "Info"; deploys "Succeeded", "In progress") with a shape before it: square (ok), circle (warn), diamond (bad), thin bar (info). Color is extra. |

All of these are in the "States" block (03) of the `#components` view, built from `../shared/states.css` and `../shared/states.html`. Dialog: "Delete this role?" with Cancel (autofocus) and "Delete role", Esc closes, focus returns to the opener, confirming shows the toast "Role deleted". Toast: `role="status"` `aria-live="polite"`, text on `--text` fill, slides up from the bottom left and hides after 4 seconds.

## H-6 Motion
Use Ember's R-3 motion primitives. The prototype's `tick` (ticker) and `v3spin` (busy spinner) keyframes stand in for them; if Ember lacks a marquee or spinner primitive, CTE adds it to Ember rather than to the theme.

| Motion | Purpose | Duration and easing | Reduced motion |
|---|---|---|---|
| Headline line reveal | Type-led entrance: each line slides up out of a mask | `--duration-reveal` 700ms, `--ease-standard` `cubic-bezier(.16,1,.3,1)`, 90ms `--stagger` per line | Shown at once |
| Display weight on scroll | The hero's weight thins from 800 to 300 over 600px of scroll | Follows scroll, no timer | Stays at 700 (`--weight-shift: 0`) |
| Section reveal | Blocks fade and rise 24px on scroll | 700ms, `--ease-standard` | Shown at once |
| Button hover and press | Fill change; arrow nudges 4px; press moves 1px | `--duration-fast` 140ms, `--ease-press` `cubic-bezier(.2,0,0,1)`; arrow 260ms | Fill change only, no movement |
| Ticker | Release-note marquee | `--duration-ticker` 36s loop, linear | Starts paused. Always has a "Pause ticker"/"Play ticker" button (moves over 5s, WCAG 2.2.2); the full text is in an `.sr` span for screen readers and the moving copy is `aria-hidden` |
| Spinner | Busy button | 700ms loop, linear | Stopped, dotted ring; the label carries the meaning |
| Toast | Announces a result | `--duration-base` 260ms slide | Appears without sliding |

Nothing flashes. Every duration goes to 0 under `prefers-reduced-motion: reduce`, and `--tilt`, `--lift` and `--parallax-scale` are 0 in this direction anyway.
