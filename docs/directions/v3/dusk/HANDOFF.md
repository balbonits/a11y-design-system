# E "dusk" HANDOFF: job tracker identity (plus the shared Ember sampler)

Identity for the **job tracker** (per neo/HANDOFF.md: job tracker = dusk, dev dashboard = kinetic, Ember UI + Storybook = neo). Dusk is soft and calm for long evenings of job hunting: warm cream paper, plum ink, coral and apricot as a sunset glow, rounded pill controls and soft low shadows; dark mode is an aubergine night with apricot accents. The prototype also draws the Ember sampler and the dev dashboard in this direction, because BRIEF.md asks each direction to show all 3 screens. **Primary project: job tracker. Builder: FSD registers the dusk theme tokens in Ember (R-2) and applies them in the job tracker. The Ember sampler and dashboard views are a style sampler only, not for build** (Chief of Creatives scope ruling, 2026-11-10). Their sections below are kept as reference for how the tokens behave; build only the job tracker parts.

- Prototype: [index.html](https://raw.githack.com/balbonits/a11y-design-system/main/docs/directions/v3/dusk/index.html) (views `#components`, `#tracker`, `#dashboard`, `#tokens`, with a light/dark toggle)
- Tokens: [TOKENS.md](TOKENS.md), [tokens.css](tokens.css), [tokens.json](tokens.json) (registry-ready, theme id `dusk`, modes `light` and `dark`), generated by `gen.py` with `../shared/tokgen.py`
- Contrast: [CONTRAST.md](CONTRAST.md), 60 pairs, 0 fails (`node ../shared/contrast.mjs dusk` from `..`)
- Screens: [handoff/](handoff/), plain and annotated, every view at every width in light and dark
- Re-run checks locally: `python3 -m http.server 8942` in `docs/directions/v3`, then from `docs/directions/v3` run `node shared/annotate.cjs dusk http://127.0.0.1:8942/dusk/index.html` and from `docs/directions` run `node v3/shared/shoot.cjs dusk http://127.0.0.1:8942/dusk/index.html`. ## H-1 Layout, mobile-first
320 is the base. Breakpoints use `min-width` only:

| Name | Query | What changes |
|---|---|---|
| base | none (320+) | One column. The header is a floating white pill bar (28px corners, `--shadow-overlay`) holding the logo and mode toggle, with the nav as a full-width row of pills under them that scrolls sideways if needed. Tracker stages are a horizontal snap-scroll row, each lane `minmax(260px, 84%)` wide so the next lane peeks in, with the visible cue "Swipe for more stages" (the arrow glyph is decorative). Stats 2 across. Side padding 1.2rem. |
| md | `(min-width: 820px)` | Nav moves inline in the pill bar. Form and Tabs panels sit 2 across (`.grid2`); stats 4 across. The States band goes 3 across at 760px (shared `states.css`). |
| lg | `(min-width: 1040px)` | Tracker lanes become a 5-column grid with no scrolling, and the swipe cue hides. |

Frames: 320, 375, 768, 1024 and 1440 for every view, in [handoff/](handoff/) as `dusk-<view>-<width>-<light|dark>.png`.

## H-2 Fluid rules
- Content max width 1160px (`.wrap`), side padding 1.2rem at every width.
- Every grid child has `min-width: 0`; the lanes row is `position: relative` so its screen-reader-only text can't widen the page (this was a 541px overflow at 375, now fixed).
- Type: display Young Serif 400, body Nunito Sans 400 to 800. Body 1.0625rem (17px), line height 1.65, never below 16px for body copy. h1 `clamp(2.5rem, 9vw, 5rem)`, h2 `clamp(1.5rem, 4.5vw, 2.2rem)`, h3 1.25rem (1.15rem in job cards), stat numbers 2.6rem, eyebrow labels 0.9rem bold `--text-muted`.
- Line length: lede 46ch, token note 60ch.
- The States section is a full-bleed band: `--surface-muted` fill drawn edge to edge with `border-image` and `clip-path`, with a 55px curved edge above and below (`--divider-shape: curve`). It never causes horizontal scroll.
- Tables sit in a focusable scroll region (`tabindex="0"`, `role="region"`, label "Components table, scrolls sideways"), so only the table scrolls.
- Dialog width `min(460px, 100vw - 2rem)`, 1.8rem padding; toast is a centered pill 1.2rem from the bottom.
- The decorative sunset glow behind the hero is `aria-hidden`, clipped to the first screen, and never takes pointer events.
- No fixed heights on text containers. Controls set `min-height`, so text spacing and 200% zoom grow them instead of clipping.

## H-3 Nav per breakpoint
- "Skip to content" is the first Tab stop and moves focus to `<main id="main" tabindex="-1">` (no visible ring on main itself).
- Header (sticky, fading `--color-bg` behind the pill bar): logo link "Ember UI v3 · E dusk" with a decorative sun mark (44px tall), `<nav aria-label="Prototype screens">` with four pill links, then the mode toggle button.
- Current link: `aria-current="page"` plus a solid `--accent` pill fill with `--accent-contrast` text (a filled shape, not only a color change); hover gives a `--surface-muted` pill.
- base to md: the nav row sits under the logo and toggle and scrolls sideways if needed (4 items fit at 320). If a product nav grows past six items, collapse it into a "Menu" disclosure (`aria-expanded`, `aria-controls`) below md.
- md and up: nav sits inline in the pill bar.
- Route change (hash) moves focus to main and scrolls to the top; each view has its own h1.
- Focus order at every width: skip link, logo, nav links left to right, mode toggle, then main content top to bottom. On the tracker, Tab goes lane by lane, left to right, and the lanes row scrolls the focused card into view. It matches visual order; the annotated shots number every stop.
- Mode toggle: label states the action ("Dark mode" or "Light mode"), no `aria-pressed`; choice stored in `localStorage` under `jdilig:mode`, else `prefers-color-scheme`. A polite toast says "Dark mode on" or "Light mode on".

## H-4 Component states
Every state has a non-color cue.

| State | Treatment |
|---|---|
| Default button | `--surface` fill, 1.5px `--border` outline (`--border-width`), fully round (`--radius-md` 999px), 48px visual height (`--control-height`), 1.4rem side padding (`--control-padding-x`), 0.6rem icon gap, bold 1rem text. Primary: `--accent` fill and border, `--accent-contrast` text. Danger: `--danger` fill, `--danger-contrast` text. Ghost: no border, `--accent` underlined text. |
| Hover | Lifts 2px (`--lift`), gains `--shadow-overlay`, fill goes to `--surface-muted`; primary goes to `--accent-hover`. Ghost: `--accent-soft` fill, no shadow. |

| Active / pressed | Drops back flat (no lift, no shadow, `--shadow-press` none) with a `--surface-muted` fill; primary keeps `--accent-hover`. |

| Fields | 52px tall, `--radius-sm` (18px) corners, `--surface` fill, 1.5px `--border`. Disabled field: dotted border, `--surface-muted` fill, `--text-muted` text, hint "Set by your admin." Checkboxes are 24px inside a 44px label row, `accent-color: var(--accent)`. |
| Loading | Busy button: `aria-busy="true"`, a 1em ring spinner and a verb label ("Saving…"). | Empty | Dashed `--border-subtle` box on `--surface-muted` with one bold line ("No rows to show."), plus one action where the copy gives one. Empty lane: "No roles in Closed." in `--text-muted`. |

| Selected (tabs, nav) | Tabs are pills in a `--surface-muted` track; selected = `--surface` fill, `--shadow-raised` and `--accent` text, `aria-selected="true"`. Nav: filled `--accent` pill plus `aria-current="page"`. |
| Status pills | Bold 0.85rem text always shown, in a `--radius-full` pill with a shape before it: dot (ok: "Passing", "Succeeded", "All green", "Stable"), rounded square (warn: "Review", "In progress", "Beta", "Watch"), diamond (bad: "Failing"), short bar (info: "Info", "2 need review"). Toast: `role="status"` `aria-live="polite"`, `--text` fill with `--color-bg` text, centered pill, hides after 4 seconds.

## H-5 Touch targets
Every target meets `--target-min` (44px), checked per view by `annotate.cjs` (no red boxes). Buttons 48px (`max(var(--control-height), var(--target-min))`), nav pills 44px, tabs 44px, logo link 44px, fields 52px, checkbox label rows 44px, footer and the TOKENS.md and CONTRAST.md links 44px-tall inline flex. Nav pills sit 0.3rem apart, but each is a filled 44px pill, so hit areas never overlap; button rows use 0.8rem gaps.

## H-6 Motion
Use Ember's R-3 motion primitives; the prototype's `v3spin` spinner keyframes stand in until then.

| Motion | Purpose | Duration and easing | Reduced motion |
|---|---|---|---|
| Section reveal | Panels fade and rise 28px as they scroll in | `--duration-reveal` 1100ms, `--ease-standard` | Shown at once |
| Sunset glow | The hero glow drifts slower than the page (`--parallax-scale` 0.12) and its hue turns up to 40deg over the page (`--hue-shift` 1) | Follows scroll, passive listener, no timer | Still glow, no drift or hue change (`--hue-shift` 0, `--parallax-scale` 0) |
| Button and card hover | Lift 2px plus a softer, larger shadow | `--duration-base`, `--ease-standard` | Shadow change only, no lift (`--lift` 0px) |
| Tabs and nav pills | Fill fades between states | `--duration-base` | Instant |
| Spinner | Busy button | 700ms loop, linear | Stopped, dotted ring; the label carries the meaning |
| Toast | Announces a result | Slides up from below the edge | Appears without sliding |

Nothing flashes and nothing moves on its own for more than 5 seconds, so dusk needs no pause control (it has no ticker). Every duration goes to 0 under `prefers-reduced-motion: reduce`, along with `--tilt` (0deg) and `--lift` (0px).
