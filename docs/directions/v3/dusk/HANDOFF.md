# E "dusk" HANDOFF: job tracker (Board page)

Dusk is the **job tracker's** identity. It's soft and calm for long evenings of job hunting: warm cream paper, plum ink, coral and apricot as a sunset glow, rounded pill controls and soft low shadows. Dark mode is an aubergine night with apricot accents. The prototype opens on the tracker's **Board** (`#tracker`, the default view). The `#components` and `#dashboard` views are a **style sampler only, not for build** (Chief of Creatives scope ruling, 2026-11-10), and each one says so on the page. This file specs the Board in full (H-1 to H-8); the sampler gets one line each where it matters.

- Prototype: [index.html](https://raw.githack.com/balbonits/a11y-design-system/main/docs/directions/v3/dusk/index.html), which opens on `#tracker`. The other views are `#components` (sampler), `#dashboard` (sampler) and `#tokens`. There's a light and dark toggle.
- Source: [TRACKER-SPEC v1.0](../../../../TRACKER-SPEC.md) (Chief of Creatives) and V3-STATE-COPY section 2 (UI Copywriter), which is pasted in full at the end of this file.
- Tokens: [TOKENS.md](TOKENS.md), [tokens.css](tokens.css) and [tokens.json](tokens.json) are registry-ready, with theme id `dusk` and modes `light` and `dark`. They're generated by `gen.py` with `../shared/tokgen.py`.
- Contrast: [CONTRAST.md](CONTRAST.md) has 60 pairs and 0 fails (`node ../shared/contrast.mjs dusk`, run from `..`).
- Screens: [handoff/](handoff/) has plain and annotated shots of every view at every width, in light and dark.
- Re-run the checks locally: start `python3 -m http.server 8942` in `docs/directions/v3`. Then run `node shared/annotate.cjs dusk http://127.0.0.1:8942/dusk/index.html` from `docs/directions/v3`, and `node v3/shared/shoot.cjs dusk http://127.0.0.1:8942/dusk/index.html` from `docs/directions`. ## H-1 Layout, mobile-first
320 is the base. Breakpoints use `min-width` only.

| Name | Query | Board |
|---|---|---|
| base | none (320+) | One column. A prototype note card comes first, then a header row with the eyebrow "Job tracker", h1 "Board" and the primary "Add role" button (it wraps under the h1 when it doesn't fit). The save error banner (when shown) is next. Then a tablist of the 5 stages, "{Stage} ({n})", which wraps onto 2 or 3 rows in a `--surface-muted` track with `--radius-xl` corners. Only the selected stage's lane shows, as a `role="tabpanel"`. Saved is selected on load. |
| md | `(min-width: 820px)` | The nav moves inline in the header pill bar. Otherwise the Board is the same as base. |
| lg | `(min-width: 1040px)` | The tabs hide and all 5 lanes sit side by side as columns, each a `role="region"` named by its heading. **Closed is collapsed by default**: its column shrinks to a single "Closed ({n})" disclosure button (`aria-expanded="false"`). Expanded, the grid is 5 equal columns. Collapsed, it's 4 equal columns plus `max-content`. |

Sampler views: `#components` and `#dashboard` keep their earlier layout (Form and Tabs 2 across from 820px, stats 2 then 4 across), and they aren't build targets.

Frames: 320, 375, 768, 1024 and 1440 for every view, in [handoff/](handoff/) as `dusk-<view>-<width>-<light|dark>.png`.

## H-2 Fluid rules
- Content max width is 1160px (`.wrap`), with 1.2rem side padding at every width.
- Every grid child has `min-width: 0`. Job titles use `overflow-wrap: anywhere`, so a long title wraps instead of widening the column.
- Lanes are `--surface-muted` with `--radius-xl` (28px) corners and 1rem padding. Job cards are `--surface` with `--radius-lg` (24px) corners, 1.1rem padding and `--shadow-raised`, and they sit 0.8rem apart. At 1040px each column is about 190px wide, and the cards grow taller rather than clip.
- Type: the display face is Young Serif 400 and the body face is Nunito Sans 400 to 800. Body text is 1.0625rem (17px) with 1.65 line height, and body copy never goes below 16px.
  - h1 `clamp(2.5rem, 9vw, 5rem)`
  - lane h2 1.25rem
  - card h3 1.15rem
  - the company line is 0.9rem bold `--text-muted`
- The reminder chip is `--accent-soft` with `--radius-sm` corners and 0.92rem text.
- Dialog width is `min(460px, 100vw - 2rem)` with 1.8rem padding, and its backdrop is `--scrim`. The Board toast is a centered `--radius-lg` box 1.2rem from the bottom, `max-content` wide but never wider than `100vw - 2rem`, with its buttons wrapping under the text.
- The decorative sunset glow is `aria-hidden`, clipped to the first screen, and never takes pointer events.
- No text container has a fixed height. Controls set `min-height`, so text spacing and 200% zoom grow them instead of clipping.
- `html` has `scroll-padding-top` 11rem (6.5rem from 820px), so the sticky header never covers a focused control.

## H-3 Nav per breakpoint
- "Skip to content" is the first Tab stop and moves focus to `<main id="main" tabindex="-1">`.
- Header: the logo link "Job tracker", with the eyebrow "Ember UI · v3 E dusk" and a decorative sun mark, goes to `#tracker`. Then comes `<nav aria-label="Prototype screens">` with Board, Components (sampler), Dashboard (sampler) and Tokens, and then the mode toggle.
- The current link gets `aria-current="page"` plus a solid `--accent` pill. Below 820px the nav is a full-width row that **wraps** (no sideways scroll). From 820px it sits inline.
- In the app, the nav is "Board", "Reminders" (badge "{n}" with sr-only ", {n} due") and "Settings", with `aria-label="Main"` (copy section 2). Reminders and Settings aren't drawn in this prototype; build them from TRACKER-SPEC with these tokens and H-4.
- A route change moves focus to main and scrolls to the top.
- Board focus order: skip link, logo, nav, mode toggle, prototype note links, "Add role", the banner's "Export data" when shown, then the stage tabs (one Tab stop; arrow keys move between them), then the selected lane's cards in order. Each card's stops are "Move or edit" and, when open, "Move to stage", Move, Edit and Delete. Then the toast's Undo and Dismiss when they're showing. From 1040px Tab goes column by column, left to right, and the Closed toggle is the last column's first stop.
- Stage tabs: ArrowLeft and ArrowRight wrap around, Home and End jump to the ends, and selection follows focus (the lane switches instantly with no fetch).

## H-4 Component states
Every state has a non-color cue. All strings are in the Copy section.

| Component | State | Treatment |
|---|---|---|
| Role card | Default | Company (0.9rem bold muted), title h3, the age line "{Stage verb} {today / yesterday / N days ago}" in `--text-muted`, and an optional reminder chip "Reminder: {text}, {Mon D}". In the app the title is a link to Role detail; in the prototype it's plain text, because Role detail isn't drawn. Hover and focus-within lift the card 2px and raise its shadow to `--shadow-overlay`. |
| Move or edit | Closed / open | A secondary button "Move or edit" with `aria-label="Move or edit {title} at {company}"`, `aria-expanded` and `aria-controls`. Opening it reveals a panel inside the card: the select "Move to stage" (the current stage selected), then the buttons **Move** (primary), Edit and Delete. Focus goes to the select when it opens. Esc closes the panel and returns focus to the button. |
| Move or edit | Moved | Move changes the stage, sets the stage date to today, saves, and re-renders. **Focus follows the card**: on mobile the destination stage's tab is selected, at 1040px the card's new column shows (Closed expands if collapsed), and focus lands on the moved card's "Move or edit" button. Then the toast "Moved to {Stage}" appears with "{title} at {company}." (polite, hides after 4 seconds). Picking the current stage and pressing Move just closes the panel. |
| Delete confirm | Dialog | A modal `<dialog>` titled "Delete this role?" with the body "{title} at {company} and its reminders will be removed.", and the buttons Cancel and "Delete role" (`--danger` fill). Focus starts on Cancel. Esc or Cancel closes it and focus returns to the card's "Move or edit" button. |
| Delete confirm | Deleted | The role is removed and saved. Focus moves to the lane's heading (`tabindex="-1"`). The toast "Role deleted" shows **Undo** and **Dismiss**, and it stays until one of them is pressed (Ember v0.2.2). Undo puts the role back in the same place, saves, focuses its "Move or edit" button and shows "Role restored" (polite, 4 seconds). Dismiss hides the toast and focuses the h1. |
| Add role | Default | A modal dialog titled "Add role" with these fields: "Job link" (`type="url"`, hint "Optional. Paste the posting URL."), "Company (required)", "Title (required)", Stage (select, default Saved), the checkbox "Set a reminder" and, only when it's checked, "Reminder date" (`type="date"`). The buttons are Cancel and "Save role" (primary). Focus starts on Job link. |
| Add role | Errors | Validation runs on submit (`novalidate`). Each error is a bold `--danger` line with a "!" badge under its field, tied with `aria-describedby` (after the hint, for Job link), and the field gets `aria-invalid="true"` and a 2.5px `--danger` border. Focus moves to the first invalid field. The rules: Job link, if filled, must start with `https://` and parse as a URL; Company and Title must not be blank; Reminder date is required when "Set a reminder" is checked. Unchecking the box clears its error. |
| Add role | Saved | The role is added to its stage and saved. Focus follows the new card (as for Moved), and the toast "Role saved" appears with "{title} at {company}." When no reminder text exists, the chip text comes from the stage (Saved: "apply before the posting closes", Applied: "follow up with the recruiter", Interviewing: "send a thank-you note", Offer: "reply to the offer", Closed: "follow up"). This is example text; Reminders owns the final copy (RULED, Known issue 7). |
| Edit role | Default / saved | The same dialog prefilled, titled "Edit role", with the button "Save changes". Changing the stage resets the age date. Focus follows the card, and the toast "Role updated" appears. |
| Board | Loading | On first load, every lane gets one `aria-hidden` skeleton card (three `--surface-muted` bars), the board gets `aria-busy="true"`, the tab counts show "…", and one polite status says "Loading roles". There's no shimmer at any motion setting. The prototype holds this for 500ms to simulate reading storage. |
| Board | Empty | When there are 0 roles, the tabs and lanes hide and a `--surface` card shows "No roles yet. Add the first one you're interested in." with a primary "Add role" button. |
| Column | Empty | "No roles in {Stage}." in `--text-muted` inside the lane. |
| Save error banner | Storage blocked or full | A `--surface` box with `--radius-xl` corners and a 2.5px `--danger` inset ring, a "!" badge, the bold text "Can't save changes on this device right now. Export your data to keep a copy." and the button "Export data". It's a static region when storage is unavailable on load, and `role="alert"` when a save fails later. The change stays on screen in memory. |
| Export data | Downloaded | Downloads `job-tracker-export.json` (every role plus an export timestamp) and shows the toast "Export downloaded". If that fails, the toast "Couldn't export. Try again." appears. |
| Closed column (1040px and up) | Collapsed / expanded | The heading is the button "Closed ({n})", with a chevron that points right when collapsed and down when expanded. It has `aria-expanded` and `aria-controls` set to the lane body. |
| Stage tabs (below 1040px) | Selected | A `--surface` pill with `--shadow-raised` and `--accent` text, plus `aria-selected="true"` and `tabindex="0"`. Unselected tabs are transparent with `tabindex="-1"`. |
| Buttons | Default / hover / focus / active / disabled | A `--surface` fill with a 1.5px `--border` outline, fully round (`--radius-md`), 48px visual height and bold 1rem text. Primary is `--accent`, danger is `--danger`. Hover lifts 2px with `--shadow-overlay`. Focus-visible is a 3px solid `--focus-ring-color` ring with 3px offset. Active drops flat with a `--surface-muted` fill. Disabled is `--surface-muted` with `--text-muted` text and a `--border-subtle` outline (**no dashed or dotted outline**), plus visible hint text giving the reason. |
| Toast buttons | Default / focus | `--color-bg` fill and border with `--text` text, the inverse of the toast. The focus ring is drawn in `--color-bg` so it shows on the dark toast. |

Prototype note and previews: a `--surface` card says "Prototype with fictional demo data, saved only in this browser." Below it are 3 links: "Empty board", "Loading" and "Can't save". Picking one shows "Previewing the {state} state." with "Exit preview", and focus moves to Exit preview. Previews never write to storage. Exit preview reloads the stored roles and focuses the h1. The preview links are prototype-only and don't ship in the app.

Data: 6 fictional roles are seeded on first visit, and every change is saved to `localStorage` under `jdilig:tracker:v1`. The prototype tests storage once on load; if storage is blocked, it uses the seed in memory and shows the banner.

The sampler `#components` view still shows the shared States band (`../shared/states.css`) as reference. Its disabled button no longer has a dashed outline.

## H-5 Touch targets
Every target meets `--target-min` (44px), which `annotate.cjs` checks per view (no red boxes) and a per-element sweep confirms at 320 and 1440 (0 under 44px).
- Buttons are 48px.
- Stage tabs, the Closed toggle, lane headings, nav pills, the logo link and the prototype note links are 44px.

- Card buttons sit 0.5rem apart and toast buttons 0.5rem apart, so filled hit areas never overlap.

## H-6 Motion
Use Ember's R-3 motion primitives. Until then, the prototype's `v3spin` spinner keyframes stand in.

| Motion | Purpose | Duration and easing | Reduced motion |
|---|---|---|---|
| Card hover and focus-within | Lift 2px with a softer, larger shadow | `--duration-base`, `--ease-standard` | Shadow change only, no lift (`--lift` 0px) |
| Buttons, tabs and nav pills | Fill fades between states | `--duration-base` | Instant |
| Sunset glow | Drifts slower than the page (`--parallax-scale` 0.12) and turns up to 40deg in hue over the page (`--hue-shift` 1) | Follows scroll through a passive listener, no timer | A still glow (both tokens 0) |
| Section reveal (sampler views) | Panels fade and rise 28px as they scroll in | `--duration-reveal` 1100ms | Shown at once |
| Spinner (sampler States band) | Busy button | 700ms loop, linear. **The spinner runs only while the element has `aria-busy="true"`.** It's removed when the action ends. | Stopped, with a dotted ring; the label ("Saving…") carries the meaning |
| Board toast | Announces a result | Appears in place (no slide) | Same |
| Skeleton cards | Loading | Static (no shimmer) | Same |

Nothing flashes, and nothing moves on its own for more than 5 seconds. Every duration goes to 0 under `prefers-reduced-motion: reduce`, along with `--lift` (0px) and `--tilt` (0deg).

## H-7 Tokens
The full light and dark table, with primitives and hex, is in [TOKENS.md](TOKENS.md), and the registry values are in [tokens.json](tokens.json) and [tokens.css](tokens.css). Shape tokens use Chief Architect's locked names (Addendum 5), plus `--scrim` and `--radius-xl` (Addendum 7).

| Token | Value | Used for |
|---|---|---|
| `--radius-sm` | 18px | Fields, reminder chip |
| `--radius-md` | 999px | Buttons (fully round) |
| `--radius-lg` | 24px | Job cards, toast, table scroll, prototype note, sampler swatches and lede |
| `--radius-xl` | 28px | Header bar, panels, dialogs, lanes, stage tab track, empty board, banner |
| `--radius-full` | 999px | Pills, tabs, nav, counts |
| stat corner (sampler) | `var(--radius-xl) var(--radius-xl) var(--radius-xl) var(--radius-sm)` | Asymmetric "speech bubble" made from existing tokens per corner (Addendum 7c). Sampler only (v1.1). |
| `--scrim` | `#1B0B1F80` (aub-950 at 50%), both modes | Dialog backdrop (Addendum 7b) |
| `--border-width` / `--border-width-strong` | 1.5px / 2.5px | Outlines / error fields, banner ring |
| `--shadow-raised` | `0 2px 6px rgb(61 19 64 / .08)` | Cards, panels, selected tab |
| `--shadow-press` | `none` | Pressed drops flat |
| `--divider-shape` | `curve` | Decorative band edges only (Addendum 7) |
| `--focus-ring-color` | coral-700 `#A8402C` (light), coral-300 `#FFA58C` (dark) | 3px solid ring, 3px offset |
| `--control-height` / `--control-padding-x` / `--control-gap` | 48px / 1.4rem / .6rem | Controls |
| `--target-min` | 44px | Every hit area |
| `--lift` / `--tilt` | -2px / 0deg | Both 0 under reduced motion |

Registered theme extras (Addendum 7a, neutral defaults in other themes): `--shadow-overlay` `0 18px 48px -18px rgb(61 19 64 / .28)`, `--parallax-scale` 0.12 and `--hue-shift` 1 (both 0 under reduced motion), plus the motion durations and easings. Fonts are `--font-display` Young Serif 400 and `--font-body` Nunito Sans 400 to 800, from Google Fonts with `display=swap`. Dusk defines no shorthand radius or focus aliases.

**Lint allowlist (Addendum 7):** the sun mark (`.sun`) and the sunset glow (`.glow`) read `--palette-apricot-300`, `--palette-coral-400` and `--palette-plum-600` directly. Both are `aria-hidden` decorative art, so they're the only allowed primitive uses. Add exactly those two selectors to the token lint's allowlist, and nothing else in dusk reads a primitive.

Contrast for every pair in both modes is in [CONTRAST.md](CONTRAST.md): text 4.5:1, and borders, focus and states 3:1, across 60 pairs with 0 fails.
