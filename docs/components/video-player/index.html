Ember UI · VideoPlayer

R-4 · prototype · neo identity

VideoPlayer

An accessible player for Ember: custom captions you can restyle, a transcript you can click to seek, an audio-description track, and keyboard control while focus is in the player. Built on the neo tokens only; switch themes at the top.

States

Static demos of each state. They use the poster frame and don't load media.

Keyboard

Shortcuts only work while focus is inside a player. They're never global, and they never fire while you're typing in a field.

KeyActionNotes
