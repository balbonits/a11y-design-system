# Tokens

Tokens come in three layers. `npm run tokens` builds them and exports `src/tokens.json`.

1. **Shared primitives** (`src/tokens/primitives.css`): the type and space ramps every theme uses.
2. **Themes** (`src/themes/<id>.css`, listed in `src/themes/registry.json`): each theme file holds its own palette, the semantic colors for light and dark, and every shape, type and motion token in the theme contract. `html[data-theme]` takes a registered id, and the first entry in the registry is the default when it's absent. `html[data-mode="light|dark"]` picks the mode, and follows `prefers-color-scheme` when absent.
3. **Components** (`src/tokens/components.css`): `--button-*`, `--field-*`, `--card-*` and the rest, each one only `var()` of a theme token. Themes never set them.

**Adding a theme takes a token file and a registry entry, nothing else.** No component, Storybook toolbar or CI script names a theme: they all read the registry. CI (`npm run lint:colors`) fails on raw colors and on any literal border-radius, border width, box-shadow or outline in component CSS, and on any retired token name.

Use the toolbar's Theme and Mode menus to switch this whole Storybook. The swatches and contrast tables below show every registered theme in light and dark.

## Contrast

Measured live from the tokens. Text pairs need 4.5:1 (WCAG 1.4.3). Borders and the focus ring need 3:1 (WCAG 1.4.11), and the focus ring is checked against the theme's border color as well as the backgrounds.

<ContrastTables />

CI checks the longer list for every registered theme with `npm run contrast` (`scripts/contrast.mjs`), plus the theme contract: every token defined, a focus ring at least 2px wide whose style is never `none`, and `--tilt` and `--lift` at 0 under reduced motion. The full table is in `docs/CONTRAST.md`.

## Shape (the theme contract)

Every theme defines every one of these, using `0` or `none` when it doesn't use one. `--control-height` is the visual height; `--target-min` (44px) is the minimum hit area, kept with an invisible inset when a control looks smaller.
