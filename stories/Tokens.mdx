# Tokens

Tokens come in three layers, one source file each, in `src/tokens/`. `npm run tokens` exports them to `src/tokens.json`.

1. **Primitives** (`primitives.css`): the raw palette, which is the only place raw colors live, plus the type, space and radius ramps.
2. **Semantic** (`semantic.css`): one set per theme and mode. The theme comes from `html[data-theme="editorial|bold|tactile"]` (editorial when absent), and the mode from `html[data-mode="light|dark"]`, which follows `prefers-color-scheme` when absent.
3. **Components** (`components.css`): `--button-*`, `--field-*`, `--card-*`, `--modal-*` and the rest. These reference semantic tokens only, and component CSS reads only these and the semantic tokens. CI fails on any raw color there (`npm run lint:colors`).

Use the toolbar's Theme and Mode menus to switch this whole Storybook. The swatches and contrast tables below always show all 6 combos.

## Shape and depth (per theme)

| Token | Editorial | Bold | Tactile |
| --- | --- | --- | --- |
| `--radius-surface` | 28px | 22px | 20px |
| `--radius-control` | 9999px (pill) | 12px | 14px |
| `--radius-field` | 14px | 12px | 12px |
| `--border-width` | 1px | 1px | 2px |
| `--shadow-2` | Soft drop shadow | Hairline plus deep glow | Hard 4px offset |

`--radius` (2px) and `--radius-full` stay in the primitives for small details.

## Motion (per theme)

| Token | Editorial | Bold | Tactile |
| --- | --- | --- | --- |
| `--duration-fast` | 120ms | 100ms | 90ms |
| `--duration-base` | 220ms | 180ms | 200ms |
| `--duration-slow` | 420ms | 360ms | 380ms |
| `--duration-reveal` | 720ms | 640ms | 600ms |

Under `prefers-reduced-motion: reduce`, every duration is 0ms, `--lift` is 0px and `--parallax-scale` is 0, and keyframe animations (dialog and toast entry, spinner) are turned off.
