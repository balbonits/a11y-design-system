# Tokens

All tokens live in one file, `src/tokens.css`. `npm run tokens` exports the same values to `src/tokens.json`. The raw palette sits underneath a semantic layer, and components only use the semantic names. Dark applies with `data-theme="dark"`, or with `prefers-color-scheme: dark` when no theme is set.

## Space

A 4px base: `--space-1` 4px, `-2` 8px, `-3` 12px, `-4` 16px, `-5` 20px, `-6` 24px, `-8` 32px, `-10` 40px, `-12` 48px, `-16` 64px.

<div style={{ display: 'grid', gap: 6 }}>
  {[1, 2, 3, 4, 6, 8, 12, 16].map((n) => (
    <div key={n} style={{ display: 'flex', alignItems: 'center', gap: 12 }}>
      <code style={{ width: 90 }}>--space-{n}</code>
      <div style={{ height: 12, width: `var(--space-${n})`, background: 'var(--accent)' }} />
    </div>
  ))}
</div>

## Radius

`--radius` is 2px (matches jdilig.me). `--radius-full` is for pills.

## Motion

| Token | Value |
| --- | --- |
| `--duration-fast` | 120ms (0ms under reduced motion) |
| `--duration-base` | 200ms (0ms under reduced motion) |
| `--ease-standard` | cubic-bezier(0.2, 0, 0, 1) |

Under `prefers-reduced-motion: reduce`, durations drop to 0 and keyframe animations (dialog and toast entry, spinner) are turned off.
