# Sintel media for the VideoPlayer stories

Storybook serves this folder at `/media/sintel/` (staticDirs, wired in R-4). The player takes these files as URL props.

| File | What it is |
|---|---|
| `captions.vtt` | English captions, the default captions track (source of truth) |
| `ad.vtt` | Audio description, a `kind="descriptions"` track (source of truth) |
| `transcript.txt` | Plain-text transcript |

These are copies of `tools/transcribe/samples/sintel/`, which is the record. Regenerate them there with `tools/transcribe/run.sh`, then copy them here; never edit these copies by hand. `cues.json` stays in tools/transcribe as a derived debug artifact and isn't used by the player. The video isn't in this folder: the player loads it from its open-licensed source URL.
