# Principles

1. **Accessible by default.** Keyboard, focus, labels and contrast are built into every component, not left to the person using it.
2. **Tokens first.** Every color, size and duration comes from `tokens.css`. Components never hard-code a value.
3. **Small and finished.** Eight components with every state done and documented, before adding a ninth.
